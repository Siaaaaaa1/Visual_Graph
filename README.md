## 🌟 V-GraphAgent: 强化学习元认知驱动的自适应视觉图探索架构

### 1. 核心科学问题 (Scientific Problems)

本方案旨在攻克“大模型+图学习”领域的四大致命缺陷：

* **捷径学习 (Shortcut Learning)**：模型倾向于只看中心节点文本或简单的邻居拼接来猜答案，而非真正理解拓扑结构。
* **上下文过载 (Context Overload)**：传统的 Graph RAG 将大量邻居摘要扁平化输入，导致严重的 Token 浪费及“Lost in the Middle”现象。
* **毛线球灾难 (Hairball Disaster)**：全局图渲染导致视觉模型（VLM）无法分辨节点间的精细拓扑关系。
* **盲目探索 (Blind Exploration)**：智能体缺乏成本意识，在强化学习中容易陷入“无意义查阅”以骗取奖励。

### 2. 多模态观测空间设计 (Multimodal Observation)

#### A. 静态雷达拓扑视图 (Radar Layout)

为了保证视觉稳定性并降低训练开销，视图在多轮对话的第一步即固定：

* **中心辐射布局**：以目标节点为原点，采用引力排斥算法（Spring Layout）部署邻居。
* **语义形态指引**：
* **方形 (■)**：目标中心节点（N0）。
* **圆形 (●)**：普通 1-hop 邻居。
* **星形 (★)**：由全局重要性（如 PageRank）或社区聚类计算出的“宏观聚类中心”，作为跨跳导航锚点。
* **三角形 (▼/▲)**：高出度（方法论 Hub）或高入度（应用 Hub）节点。

基于社区的算法进行颜色的绘制，颜色越接近的节点越相似，节点的embedding使用文本的embedding来进行计算，使用某种方法进行节点的聚合和聚类中心的搜索。（但是需要考虑的是，如果使用Leiden方法进行社区的划分，那么如何结合社区的链接和节点的embedding更合适？如何考虑颜色的绘制？）


* **真实 ID 锚点**：图上直接标注数字 ID（如 `1024`, `38491`），实现视觉特征与文本 Prompt 的像素级对齐。

#### B. 漏斗式文本目录 (Funnel-style Prompting)

Prompt 不再一次性提供摘要，而是分层展现：

* **一级信息 (Topic)**：利用简单方法预先提取题目和摘要中的关键词（如：Graph Neural Network, BERT）作为廉价先验，放到初始环境prompt中。
* **二级信息 (Title/Abstract)**：题目和摘要被锁定在环境后端。只有当模型通过 ID 调用工具时，才作为环境反馈（Observation）返回。

### 3. 认知架构与动作空间 (Cognitive Architecture)

#### A. 元认知思维链 (Metacognitive CoT)

强制模型在采取动作前进行自我审视，格式如下：
先进行充分的思考，然后再回答下面的问题：
* **[假设生成]**：基于当前看到的中心节点的标题和文本与周围节点的拓扑关系，初步判断其属于哪个领域。
* **[置信度评估]**：基于目前的“主题列表”，我是否有 90% 以上的把握？
* **[动作决策]**：如果不确定，根据视图发现 N23 是一个高引用的倒三角节点，决定查阅其摘要以验证假设。

#### B. 极致收敛的动作集

* **查阅摘要**：`<action>check_node(ID)</action>`
* **最终提交**：`<action>final(Category)</action>`

### 4. 强化学习建模 (RL Formulation)

采用 **GRPO (Group Relative Policy Optimization)** 算法进行训练，核心在于通过非线性奖励重塑（Reward Shaping）刻画模型的“成本边界”：

#### 奖励函数数学表达

设 $n$ 为查阅节点的次数，$R_{total}$ 为最终得分：

$$R_{total} = R_{target} + \sum_{i=1}^{n} C_{explore}(i) + P_{blind}$$

* **目标奖励 $R_{target}$**：正确得 $+1.0$，错误得 $-1.0$。
* **动态探索成本 $C_{explore}(i)$**：（到底应不应该加？）
* 当 $i \le 2$ 时，$C = -0.01$（鼓励基础探索）。
* 当 $i > 2$ 时，$C$ 随次数指数级增长（如 $-0.05, -0.15, -0.4...$），逼迫模型学会“克制”。


* **盲目自信惩罚 $P_{blind}$**：
* 若模型在 $n=0$（未查阅任何摘要）的情况下猜错，则 $P_{blind} = -2.0$。

### 5. 训练与实验 Pipeline

#### A. 训练阶段

1. **专家轨迹预热 (SFT)**：合成数千条基于“先看 Hub 节点、后求证 N0 摘要”的高质量交互轨迹。
2. **GRPO 策略对齐**：在 **AppWorld** 或 **OGBN-Arxiv** 仿真环境中运行 RL，让模型自发形成置信度边界。

#### B. 实验基线 (Baselines)

* **Text-only Agent**：剥离视觉，仅给文本 ID 对照表，验证视觉拓扑颜色的“直觉引导”价值。
* **All-Neighbors RAG**：对比全量摘要拼接方案的 Token 消耗。
* **传统 GNN (GCN/GraphSAGE)**：作为性能底线。

#### C. 核心指标 (Metrics)

* **准确率 (Accuracy)**：特别是在异质图和边界节点上的表现。
* **系统性价比 (Token Efficiency)**：计算达到相同准确率所消耗的平均 Token 数。
* **有效检索率 (EIRR)**：量化模型查阅的节点中，有多少是真正对决策有贡献的。
